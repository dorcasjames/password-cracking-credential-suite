# Password Cracking & Credential Attack Suite

A 5-module ethical password security testing toolkit.
Built by Adebamigbe Dorcas Adeyemi | May 2026

## Modules
- dictionary_generator.py — Generates custom wordlists
- hash_extractor.py — Extracts password hashes
- bruteforce_simulator.py — Simulates cracking attacks
- password_strength.py — Analyzes password strength
- audit_report.py — Full automated audit report

## Usage
python dictionary_generator.py
python hash_extractor.py
python bruteforce_simulator.py
python password_strength.py
python audit_report.py

## Requirements
pip install passlib colorama
